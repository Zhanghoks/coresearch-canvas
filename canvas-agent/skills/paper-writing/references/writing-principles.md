# Writing principles

Front-load What / Why / So What in title, abstract, introduction, and the hero figure.

Calibrate each claim to evidence, then state it directly. Generic caveats live in Limitations. Unsupported numbers become `<!-- DATA_NEEDED -->` or a labeled gap, never a plausible table.

Do not copy prose, claims, or terminology from a style-ref paper. Style-ref is structure only.

Bibliography: fetch via `bibtex_fetch.py` or `arxiv_fetch.py`. Memory is not a source.
