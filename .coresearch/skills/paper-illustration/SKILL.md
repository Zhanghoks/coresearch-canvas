# Paper Illustration

概念图，不是数据曲线。数据用 `paper-figure`，分层框图用 `figure-spec`。

1. 先写一句话：这张图比较/展示什么。
2. 能用 `figure-spec` JSON 表达就走 `figure-spec`。
3. 需要手绘时列出部件、箭头含义和不要出现的装饰。
4. 图注写比较对象。禁止无 caption 的装饰图。

完成标准：有可编译图文件，或有可交给设计师的部件清单。
