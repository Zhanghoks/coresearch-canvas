# 画布节点操作手册

产品主线是九种**研究主流程节点**。底部工具栏、双击创建菜单和左侧元素筛选只放这些类型。文本、图片、视频、音频、生成配置、PDF、网页等仍可作为附属能力存在，但不进主入口。

## 研究主流程节点

| 类型 | 作用 |
| --- | --- |
| Seed | 薄种子：确认主题理解，不含完整方法与评估 |
| Direction | 研究方向；可深入 Deep Dive 与文献 |
| Research Question | 可研究的问题表述 |
| Problem | 问题界定与证据 |
| Hypothesis | 可检验假设 |
| Approach | 总体方案；提交下一步时需同时带 Method 与 Evaluation |
| Method | 方法协议 |
| Evaluation | 评估矩阵；可与 Method 互相修订 |
| Idea | 综合上游对象形成可评审 Idea |

### 卡片怎么用

- 空卡片：居中类型图标，可「自己写摘要」或「让 Agent 帮忙」。
- 卡片显示类型、标题和摘要；选中时可能出现「已确认」或「文档空骨架」。
- 双击打开一篇 Markdown 文档，左侧目录来自全部 `##`。新建节点预填权威章节骨架；打开旧空文档不会自动套模板。可用「补全骨架」追加缺失的官方标题。
- 下方输入条可把意图发到右侧 Agent；写入画布仍需用户确认。
- 阶段推进：对话里探索 → 用户明确保留 → Agent 走 `research_workflow_advance` 的 `commit` / `synthesize`。

### 创建方式

- 底部「＋」、双击空白、左侧筛选：仅九种研究节点。
- 空画布起始入口：优先「创建 Seed」或「与 Agent 对话」。

更多原则见 [研究交互思路](/docs/progress/research-interaction)。

## 文献与材料（非主流程入口）

- `web` / `pdf`：Deep Dive 文献层常用，可从 Agent 创建或后续材料入口接入，不进底部主流程工具栏。
- 框架 / 分组：仅组织视图，不会把拖入的材料自动改成 Method 等研究类型。

## 附属多媒体节点（遗留能力）

上传、粘贴、侧栏资产或生成配置仍可创建文本 / 图片 / 视频 / 音频节点，并走原有生成、裁剪、遮罩等流程。这些能力来自分叉前产品，**不是**当前研究主流程入口。若只需研究编排，可忽略本节。

### 文本 / 图片 / 视频（摘要）

- 文本：双击编辑；可连接生成配置做改写或下游生成。
- 图片：上传或生成；支持裁剪、局部编辑等工具栏操作。
- 视频：上传或生成；可截取帧为图片节点。

详细接口与参数以配置页和节点面板为准。
