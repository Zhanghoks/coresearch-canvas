# Paper Rebuttal

1. 把审稿意见按 reviewer 拆成条目，标 accept / clarify / cannot。
2. 每条回复：先一句直接回答，再给证据指针（表、图、定理、commit）。没有新实验就写清楚，不承诺做不到的实验。
3. 礼貌、具体、不贬低审稿人。相同问题合并，不复制粘贴。
4. 写出 `paper/rebuttal.md`。若需改正文，列出将改的段落，再改用 `paper-write`。

完成标准：每条意见都有 disposition 和回复草稿。
